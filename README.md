# 도파민사냥꾼 100점 급등 자동발송 서버

바이낸스 USDⓈ-M 무기한 선물의 최근 15분 거래대금 상위 30개를 1분마다 감시하고, 100점 급등 예상 종목만 도파민사냥꾼 텔레그램으로 전달합니다.

## 발송 기준

- 1분봉 롱 100점
- 5분봉 롱 100점
- 숏과 관망은 발송하지 않음
- 조건 충족 종목을 최대 5개까지 한 메시지로 발송
- 100점 종목이 없으면 발송하지 않음
- 1분마다 다시 검사
- `POSITION_SYMBOLS`(기본값 `ENA`)는 4시간봉·일봉으로 별도 대응을 계산
- 두 봉 모두 상승이면 `보유`, 모두 하락이면 `손절`, 엇갈리면 `관망`
- 하락 또는 혼조에서는 `물타기 금지`, 상승 정렬과 비과열이 함께 확인될 때만 `소액 분할 검토`
- 동일 대응은 상태가 바뀔 때 우선 알리고, 바뀌지 않으면 4시간 간격으로만 재알림
- `POSITION_MARKET=FUTURES`이면 청산 위험 때문에 추세와 무관하게 `물타기 금지`

## 실행

`BACKGROUND_SCAN_SECRET`를 MAP 시그널 센터와 동일하게 설정한 뒤 `npm start`를 실행합니다. `/health`에서 최근 스캔 상태를 확인할 수 있습니다.
